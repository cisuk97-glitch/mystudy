# MY SPECIAL ENGLISH 💖 고1 내신 대비 비밀 노트
> **고1 예고 여학생 맞춤형 클라우드 단어 학습 & 주관식 스마트 채점 & PWA 내신 관리 시스템**

---

## 🌟 주요 특징 및 차별점

1. **아이패드 100% 순정 네이티브 앱 (PWA)**
   - Safari 브라우저 상단 주소창과 하단 툴바가 전혀 없는 전체 화면(Standalone) 네이티브 앱으로 동작합니다.
   - 고해상도 파스텔톤 레티나 다이어리 아이콘 (`icon-192`, `icon-512`, `apple-touch-icon`) 적용.
   - 독서실, 학원, 집 어디서든 가볍고 쾌적하게 구동됩니다.

2. **Supabase 클라우드 실시간 동기화**
   - 학생이 아이패드로 단어를 외우고 주관식 시험을 치르면, 부모님은 맥북이나 스마트폰으로 **실시간 시험 성적(점수, 정답률, 획득 별)과 누적 오답 로그를 원격에서 즉시 확인**할 수 있습니다.
   - 미연동 시에도 로컬 브라우저 저장소(LocalStorage)로 자동 안전 fallback 지원.

3. **완전 무음 환경 보장 (독서실 최적화)**
   - 버튼 클릭음, 탭 전환음, 채점 효과음 등 불필요한 소음을 100% 제거하여 독서실에서도 안심하고 사용할 수 있습니다.
   - 오직 학생이 직접 누르는 **[🔊 영단어 발음 듣기] Web Speech TTS**만 작동합니다.

4. **컴팩트 20단어 공부 뷰**
   - 한 화면에 20단어씩 좌/우 2열로 깔끔하게 배치 (40단어 기준 총 2페이지).
   - 꿀팁 상자 없이 영단어 바로 옆에 직관적인 교재 한글 뜻 배치.
   - 가림판 4종 토글 (`👀 전체 보기`, `🙈 뜻 숨기기`, `🙈 단어 숨기기`, `🙈 모두 숨기기`) 및 터치 시 즉시 공개.

5. **오타 및 띄어쓰기 참작 스마트 채점 알고리즘 (핵심 ⭐)**
   - 공백(띄어쓰기) 및 특수문자 무시.
   - 쉼표/슬래시로 나열된 복수 뜻 중 **한 가지만 써도 정답** 인정.
   - 한글 초성·중성·종성(자모) 분해 후 편집거리 유사도 **85% 이상**이면 오타 참작 정답 인정 + `[💡 살짝 오타: 원래 표기는 '...']` 피드백 안내.
   - 영단어 5자 이상 1타, 8자 이상 2타 오타 및 순서 바뀜 허용.
   - 동사 어근(예: '시작하다' ➔ '시작') 인정.

6. **접근 권한 및 관리자 보안 (PIN 인증)**
   - **학생 (무로그인 프리패스)**: 아이콘 터치 시 로그인 없이 즉시 단어장 및 시험 화면 진입.
   - **부모님 (4자리 PIN 인증)**: 사이드바의 관리자 메뉴 클릭 시 4자리 PIN(기본: **0000**) 입력 후 [📊 실시간 시험 성적 & 오답 리포트], [교재 PDF 등록], [새 대단원 추가] 이용 가능.

7. **순수 클라이언트 PDF 단어 표 파서 (PDF.js)**
   - 외부 유료 AI API 없이 브라우저 내장 PDF.js로 교재 단어장 PDF의 표를 1초 만에 파싱하여 Supabase DB에 일괄 등록(Batch Insert).

8. **내신 대비 파이널 오답 단어장 (A4 인쇄 최적화)**
   - 한 번이라도 틀렸던 모든 핵심 단어들을 모아 시험 직전 최종 점검.
   - **[🖨️ A4 용지로 인쇄하기]** 버튼 클릭 시 웹 헤더와 버튼을 자동으로 숨기고 종이 시험지 형태로 완벽하게 출력됩니다.

9. **단어/단원/영작문 다중 시험 유형 통합 성적 관리 (NEW)**
   - 단어 주관식 시험(`VOCAB`)뿐만 아니라 단원 평가(`UNIT`), 서술형 영작문(`WRITING`) 시험 점수까지 통합 관리.
   - 부모님 전용 대시보드에서 시험 유형별 배지 표기 및 필터 탭(`전체 | 단어 | 단원 | 영작`) 제공.

## 🚀 Supabase 클라우드 데이터베이스 3분 세팅 가이드

1. **Supabase 프로젝트 생성**:
   - [Supabase 웹사이트](https://supabase.com/)에 접속하여 로그인(GitHub 등) 후 **[New Project]**를 생성합니다.
   - 프로젝트 이름(예: `my-special-english`)과 데이터베이스 암호를 입력하고 생성합니다.

2. **SQL 스키마 실행 (원클릭)**:
   - 좌측 메뉴에서 **SQL Editor**로 이동합니다.
   - 본 프로젝트의 `schema.sql` 파일 내용을 복사하여 붙여넣고 **[Run]**을 누릅니다.
   - `lessons`, `vocab_words`, `test_records`, `test_wrong_history`, `app_meta` 테이블과 RLS 정책 및 비상 3과 기본 40단어가 자동으로 생성됩니다!

3. **API 키 확인**:
   - 좌측 하단 **Project Settings → API** 메뉴로 이동합니다.
   - **Project URL**과 **anon public key**를 복사합니다.

4. **웹앱에 연동하기**:
   - 배포된 웹앱에서 좌측 상단 '☰' 서랍 메뉴를 엽니다.
   - **[🔑 관리자 / 부모님 인증 (PIN 입력)]**을 누르고 기본 PIN인 `0000`을 입력합니다.
   - **[☁️ 클라우드 설정]** 버튼을 누르고 복사한 `Project URL`과 `anon key`를 입력 후 **[연동 및 저장]**을 누르면 끝!

## 🌐 Vercel 1분 무료 배포 가이드

본 프로젝트는 외부 번들러나 백엔드 서버 없이 브라우저에서 직접 실행되는 순수 정적 웹 애플리케이션입니다.

1. **GitHub 리포지토리 생성 및 푸시**:
   ```bash
   git init
   git add .
   git commit -m "feat: MY SPECIAL ENGLISH PWA & Supabase Cloud"
   git remote add origin https://github.com/사용자이름/my-special-english.git
   git push -u origin main
   ```

2. **Vercel에서 배포하기**:
   - [Vercel](https://vercel.com/) 대시보드에서 **[Add New...] → [Project]**를 클릭합니다.
   - GitHub 리포지토리를 선택(Import)합니다.
   - **Framework Preset**: `Other` (기본값)
   - **Build Command**: 비워둠 (빌드 필요 없음)
   - **Output Directory**: `./` (기본값)
   - **[Deploy]** 버튼을 클릭하면 약 10초 만에 `https://your-project.vercel.app` 형태의 고유 HTTPS 주소가 발급됩니다!

## 📱 아이패드(iPad) 홈 화면에 네이티브 앱으로 추가하는 방법

1. 아이패드의 **Safari(사파리)** 브라우저를 열고 배포된 Vercel 주소로 접속합니다.
2. Safari 상단(또는 하단) 툴바의 **[공유(Share)] 아이콘** (네모 박스 위로 화살표 아이콘 ⬆️)을 탭합니다.
3. 목록에서 **[홈 화면에 추가 (Add to Home Screen)]**를 선택합니다.
4. 이름이 `내신영어` 또는 `MY SPECIAL ENGLISH`로 표시되는지 확인하고 **[추가]**를 누릅니다.
5. 아이패드 홈 화면에 생긴 귀여운 파스텔톤 앱 아이콘을 터치하면, **사파리 주소창이 전혀 없는 100% 풀스크린 네이티브 앱**으로 열립니다!

## 📂 프로젝트 파일 구조

```
English3/
├── index.html          # 메인 UI (파스텔 다이어리 테마, PWA 메타 태그, PIN 모달, 리포트 모달)
├── style.css           # 반응형 스타일, 다이어리 비주얼, A4 인쇄(@media print) 스타일
├── app.js              # 프론트엔드 비즈니스 로직 (단어 뷰, 주관식 테스트, 오답 집계)
├── grading.js          # 스마트 채점 엔진 (한글 자모 분해, 85% 유사도 오타 참작, 복수 뜻)
├── supabaseClient.js   # Supabase JS 클라이언트 연동 (CRUD 및 LocalStorage fallback)
├── pdfParser.js        # PDF.js 기반 교재 단어장 표 초고속 추출 파서
├── words.js            # 비상 3과 The Gift of Art 40단어 백업 데이터
├── schema.sql          # Supabase SQL 에디터 원클릭 실행 스키마 (테이블, RLS, 3과 시드)
├── manifest.json       # PWA 매니페스트 (Standalone, theme_color, app icons)
├── sw.js               # 오프라인 지원을 위한 PWA 서비스 워커
├── vercel.json         # Vercel 배포 최적화 설정 파일
└── icons/              # 레티나 고해상도 앱 아이콘
    ├── icon.svg
    ├── icon-192.png
    ├── icon-512.png
    └── apple-touch-icon.png
```
