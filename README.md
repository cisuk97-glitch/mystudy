# MY SPECIAL ENGLISH 💖 고1 내신 대비 비밀 노트
> **고1 맞춤형 올인원 내신 대비 학습 시스템**  
> 단어 암기부터 서술형 영작, PDF 단원평가 시험지 뷰어, 실시간 오답노트, 부모님 원격 성적 모니터링까지 지원하는 PWA & 클라우드 학습 플랫폼입니다.

---

## 🌟 주요 핵심 기능

### 1. 📖 단어 암기 & 스마트 공부 뷰
- **한 화면 20단어 2열 컴팩트 배치**: 스크롤 부담 없이 20단어씩 한눈에 집중 학습 (교재 한글 뜻 직관적 배치).
- **인터랙티브 가림판 4종 토글**: `👀 전체 보기`, `🙈 뜻 숨기기`, `🙈 단어 숨기기`, `🙈 모두 숨기기` 및 개별 카드 터치 시 즉시 공개.
- **독서실 최적화 100% 무음 환경**: 불필요한 효과음을 배제하고, 학생이 직접 누르는 **[🔊 발음 듣기] Web Speech TTS**만 작동.

### 2. ✍️ 주관식 단어 시험 & 오타 참작 채점 엔진 (`grading.js`)
- **한글 자모 분해 편집거리 알고리즘**: 초성·중성·종성 분해 후 유사도 **85% 이상** 시 오타 참작 정답 처리 및 `[💡 살짝 오타 안내]` 피드백 제공.
- **다의어 복수 정답 유연성**: 쉼표/슬래시로 구분된 여러 뜻 중 **한 가지만 적어도 정답** 인정.
- **공백·특수문자 무시 & 동사 어근 인정**: 불필요한 띄어쓰기 오답 방지 및 동사 기본형 인정.
- **영단어 철자 허용**: 5자 이상 1타, 8자 이상 2타 철자 뒤바뀜 오타 참작.

### 3. 🖋️ 서술형 영작문 학습 (`WRITING`)
- **단원별 핵심 서술형 문장 마스터**: 한글 프롬프트 제시 후 영어 문장 타이핑 테스트.
- **문장별 독립 학습 관리**: 문항별 응시 횟수, 오답 횟수, 완벽 암기(`is_mastered`) 여부 데이터베이스 추적.

### 4. 📄 PDF 단원평가 & 모의고사 시험 뷰어
- **아이패드 최적화 분할 뷰 (Split View)**: 좌측 PDF 시험지 원본 뷰어 + 우측 인터랙티브 OMR / 서술형 답안 입력창 동시 배치.
- **자동 채점 & 멀티모달 해설 뷰어**: 채점 즉시 상세 해설 모달 제공 (텍스트 해설 및 📸 2단 이미지 캡처 해설 지원).
- **시험지 및 단어장 PDF 간편 등록**: 교재 단어장 PDF 자동 파싱(`pdfParser.js`) 및 모의고사 PDF 업로드(Supabase Storage `test_papers` 버킷 연동).

### 5. 📝 스마트 오답노트 & 파이널 인쇄
- **오답노트 관리 시스템**: 시험별 틀린 문제 자동 수집, 학생 제출 답과 정답 비교, 나만의 핵심 메모(`notes`) 작성 및 실시간 저장.
- **A4 시험지 인쇄 최적화 (`@media print`)**: 헤더/버튼을 자동 숨기고 깔끔한 종이 시험지 형태로 바로 출력 가능한 파이널 오답 단어장 지원.

### 6. 👨‍👩‍👧 부모님 원격 모니터링 & 관리자 모드 (PIN 보안)
- **4자리 PIN 인증 보안**: 기본 PIN(`0000`) 인증을 통과한 관리자만 설정 및 리포트 접근 가능 (PIN 자체 변경 지원).
- **실시간 시험 성적 리포트**: 단어(`VOCAB`), 단원평가(`UNIT`), 영작문(`WRITING`) 전 유형 시험 결과, 정답률, 풀이 시간, 획득 별, 누적 오답 원격 확인.
- **단원 및 시험지 통합 관리**: 과목별 단원 추가/수정/삭제 및 등록된 시험지 목록 관리.

### 7. ⭐️ 동기부여 게이미피케이션
- 누적 성적에 따른 별(Stars) 획득 및 별 보관함 시스템.
- 회차별 취약 단어 빈도 분석 및 오답 집중 재시험 모드 제공.

## 🛠️ 기술 스택

| 영역 | 기술 및 도구 | 설명 |
|---|---|---|
| **Frontend** | HTML5, Vanilla CSS3, ES6+ JavaScript | 빌드 도구 없는 초경량 아키텍처, 파스텔 다이어리 테마 |
| **PDF Processing** | PDF.js | 클라이언트 사이드 고속 PDF 렌더링 및 표 파싱 |
| **Cloud Backend** | Supabase (PostgreSQL 15, Storage) | 실시간 데이터 동기화, RLS 보안 정책, PDF 파일 스토리지 |
| **Local Backend** | Python 3 + SQLite (`server.py`) | 로컬 오프라인 실행 및 개발용 내장 서버 (`:8089`) |
| **Desktop App** | Tauri (Rust) | 경량 크로스 플랫폼 데스크톱 네이티브 패키징 (`src-tauri`) |
| **Mobile / PWA** | Web App Manifest, Service Worker | 아이패드/아이폰 Safari 전체화면 Standalone 웹앱 지원 |
| **Hosting** | Vercel | 정적 웹 호스팅 및 자동 HTTPS 배포 |

## ☁️ Supabase 클라우드 설정 가이드

1. **프로젝트 생성**: [Supabase](https://supabase.com/)에서 새 프로젝트를 생성합니다.
2. **데이터베이스 스키마 적용**:
   - Supabase 콘솔 좌측 **SQL Editor**로 이동합니다.
   - 프로젝트의 `schema.sql` 전체 내용을 복사하여 붙여넣고 **[Run]**을 실행합니다.
   - 9개 테이블(`subjects`, `lessons`, `vocab_words`, `test_records`, `test_wrong_history`, `app_meta`, `pdf_tests`, `wrong_answers`, `writing_sentences`)과 `test_papers` 스토리지 버킷 및 보안 정책이 자동 구성됩니다.
3. **API 키 복사**:
   - **Project Settings → API**에서 `Project URL`과 `anon public key`를 복사합니다.
4. **웹앱 연동**:
   - 웹앱 사이드바 ☰ → **[👨‍👩‍👧 관리자 메뉴]** → PIN `0000` 입력 → **[☁️ 클라우드 설정]**.
   - URL과 anon key를 입력하고 **[연동 및 저장]**을 누르면 동기화가 활성화됩니다.
